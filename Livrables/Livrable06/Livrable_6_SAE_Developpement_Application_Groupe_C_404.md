
# Livrable 6 : Présentation de sources secondaires de données   

Pour compléter les données fournies par IMDb, nous avons recherché d’autres sources qui pourraient nous apporter des informations supplémentaires et utiles à notre application, notamment sur les films, les séries, et les autres productions audiovisuelles.

Pour la source trouvées, celle qui nous sembla la plus intéressante est **The Movie Database** (TMDB) : https://www.themoviedb.org/?language=fr

Nous avons choisi cette source car elle propose plusieurs informations qui ne sont pas présentes dans les fichiers IMDb et qui pourraient être intéressantes pour notre application.

Parmi celles-ci, nous avons retenu trois élément principaux : 

## 1. Les affiches des oeuvres
L’ajout des affiches permettrait de rendre notre site plus agréable visuellement. Lorsqu’un effectue une recherche il pourrait directement voir son affiche à côté du titre? Cela permettrait aussi de reconnaître plus facilement les œuvres, plutôt que d’avoir uniquement une liste de noms. 

## 2. Les synopsis
Les fichiers IMDb ne contiennent pas de résumé des œuvres. Grâce à TMDB, nous pourrions ajouter un synopsis sur chaque fiche afin que les utilisateurs puissent avoir une idée de l’histoire d’un film ou d’une série sans avoir besoin de faire une recherche sur un autre site.

## 3. Les budgets et les recettes
TMDB propose également des informations sur les budgets et les recettes de certains films. Ces données pourraient nous permettre d’ajouter une partie statistique à notre application. Par exemple, nous pourrions comparer le budget d’un film avec l’argent qu’il a rapporté.

L’utilisation des données de TMDB est autorisée gratuitement dans le cadre d’un projet non commercial comme le nôtre. Cependant, nous devons respecter certaines conditions, notamment mentionner TMDB comme source et faire attention aux droits d’auteur concernant les affiches des œuvres.
